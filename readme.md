# JUNTXS — versión 1.0

Proyecto web/PWA listo para ejecutar con React + Vite.

## Incluye
- Landing pública de JUNTXS.
- Registro/entrada demo +18.
- Descubrir perfiles, filtros visuales, likes, descartes y Super Like.
- Matches.
- Mensajería local con interfaz de videollamada.
- Perfil y álbum privado.
- Centro de seguridad, bloquear/reportar/SOS informativo.
- Plan gratuito y JUNTXS+ de $129/mes.
- PWA instalable.
- Persistencia básica en localStorage.

## Ejecutar
```bash
npm install
npm run dev
```
Abrir la URL que muestre Vite.

## Importante para producción
Esta entrega es una aplicación funcional de interfaz y demo local. Para lanzar una app real con usuarios reales hay que conectar backend/autenticación, base de datos, almacenamiento de fotos, moderación, WebRTC y una pasarela de pagos (por ejemplo Mercado Pago), además de políticas legales y controles de edad.
